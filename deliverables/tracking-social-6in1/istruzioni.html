Istruzioni di installazione

Prodotto: Tracking Unificato Icone Social (6-in-1) via GTM

1. Cosa hai ricevuto

  • container.json – esportazione del contenitore GTM già configurato
  • Queste istruzioni

2. Come importare il container

  1. Accedi a Google Tag Manager.
  2. Seleziona il container del tuo sito.
  3. Admin → Container → Import Container → carica container.json.
  4. Scegli Merge o Overwrite in base alla situazione del tuo container.
  5. Conferma l’importazione.

3. Cosa controllare dopo l’import

  • I trigger/click sulle icone social (Facebook, Instagram, LinkedIn, X, YouTube, WhatsApp/TikTok)
  • I nomi degli eventi inviati a GA4
  • Eventuali parametri personalizzati (canale, posizione del click, ecc.)

4. Pubblicazione

  1. Attiva la modalità Anteprima di GTM.
  2. Clicca le varie icone social e verifica che gli eventi partano correttamente.
  3. Controlla in GA4 DebugView.
  4. Pubblica il container.
Nota: Se le tue icone social usano classi CSS o strutture HTML diverse, potrebbe essere necessario aggiornare i selettori dei trigger. Contattaci pure a support@easytag.com se hai bisogno di supporto.
