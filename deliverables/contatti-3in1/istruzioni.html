Istruzioni di installazione

Prodotto: Pacchetto Contatti 3in1 (Telefono + Email + WhatsApp)

1. Cosa hai ricevuto

  • container.json – esportazione del contenitore GTM già configurato
  • Queste istruzioni

2. Cosa traccia questo container

  • Click sui link tel: (chiamate)
  • Click sui link mailto: (email)
  • Click sui link WhatsApp (wa.me e whatsapp)

3. Come importare il container

  1. Accedi a Google Tag Manager.
  2. Seleziona il container del tuo sito.
  3. Admin → Container → Import Container → carica container.json.
  4. Scegli Merge o Overwrite.
  5. Conferma l’importazione.

4. Cosa personalizzare

  • Variabile ID Conversione - EasyTag → inserisci il tuo Conversion ID di Google Ads
  • Conversion Label di ogni tag (attualmente impostata su ETICHETTA_QUI)

5. Test e pubblicazione

  1. Attiva la modalità Anteprima di GTM.
  2. Clicca su un numero di telefono, un’email e un link WhatsApp.
  3. Verifica che gli eventi partano correttamente.
  4. Pubblica il container.
Nota: Se i tuoi link WhatsApp usano formati particolari, verifica i trigger. Per supporto scrivi a support@easytag.com.
