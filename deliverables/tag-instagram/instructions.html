01

This guide

The steps, in the order you should follow them.

2 Import the container

Open tagmanager.google.com with the account that owns the site.

  1. 01
    Open the site container. If you do not have one, create a Web container.
  2. 02
    Go to this menu:
    Admin→Container→Import container
  3. 03
    Choose the container.json file from the email.
  4. 04
    Merge if the container already has tags. Overwrite only if it is empty.
  5. 05
    Read the preview and confirm.
If you are unsure Always choose Merge. It does not delete tags that are already there.

3 What to customise

  • Google Ads Conversion ID and Label. Put your values in the variables already in the container.
  • GA4 event. The expected name is instagram_click. Change it only if your property already uses another name.
  • Trigger. It fires on the link described below. A button without that link needs a different trigger.
Check the link The icon must be a link to instagram.com. A button without href does not fire.

4 Test and publish

  1. 01
    In GTM click Preview and connect the site.
  2. 02
    Click the link on the page.
  3. 03
    In the debug panel, check that the tag fires.
  4. 04
    Open GA4 → DebugView and, if you use Ads, Tag Assistant.
  5. 05
    Then click Submit and Publish.

5 If something does not fire

Email us the site address and a screenshot of the GTM preview. We will adjust the trigger.
