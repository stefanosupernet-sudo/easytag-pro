Dynamic remarketing via GTM

Da usare dopo la consegna del container e l’allineamento con feed e campagne.

Indice
  1. Prerequisiti
  2. Import in GTM
  3. Parametri prodotto
  4. Test e pubblicazione
  5. Supporto

1 Prerequisiti

  • Feed prodotti (Merchant Center o feed custom) collegato alle campagne Dynamic Remarketing
  • Campagne / asset Dynamic Remarketing su Google Ads (o pronti da creare)
  • Eventi sito che espongono gli ID prodotto allineati al feed
CriticoSe l’ID prodotto nel sito non coincide con quello del feed, il remarketing dinamico non mostra i prodotti giusti.

2 Import in GTM

  1. Apri Tag Manager e seleziona il container.
  2. Admin → Container → Import Container → carica il file ricevuto.
  3. Usa Merge se hai già altri tag.
  4. Conferma dopo l’anteprima.

3 Parametri da verificare

  • ID prodotto, nome, prezzo (e altri campi richiesti dal formato remarketing)
  • Eventi: view_item, add_to_cart, purchase, ecc.
  • Conversion ID / Label Ads se previsti nel progetto
SuggerimentoConfronta un ID dal feed con lo stesso prodotto in pagina: devono essere identici (stesso formato, stessi zeri iniziali se presenti).

4 Test e pubblicazione

  1. Anteprima GTM: naviga schede prodotto e carrello.
  2. Verifica che i parametri prodotto partano su ogni evento rilevante.
  3. Controlla con gli strumenti di debug Ads / Tag Assistant se disponibili.
  4. Pubblica il container.

5 Supporto

Dubbi su allineamento feed ↔ eventi o su campagne Ads? Scrivici con account e esempi di ID prodotto.
