Questa guida

Istruzioni passo-passo per importare, personalizzare e pubblicare.

2 Importare il container in GTM

Apri tagmanager.google.com e accedi con l’account che gestisce il sito.

  1. Seleziona (o crea) il container del sito su cui vuoi attivare il tracking.
  2. Vai in Admin → Container → Import Container
  3. Carica il file container.json ricevuto via email.
  4. Scegli l’area di lavoro (Workspace) in cui importare.
  5. Opzione di import:
    • Merge — se hai già tag attivi (consigliato nella maggior parte dei casi)
    • Overwrite — solo se il container è nuovo o vuoto
  6. Controlla l’anteprima delle modifiche e conferma l’importazione.
Suggerimento Se non sei sicuro, usa sempre Merge. Eviti di cancellare tag già presenti nel container.

3 Cosa personalizzare dopo l’import

Il container è un modello pronto. Prima di pubblicare verifica questi punti:

  • Conversion ID / Label Google Ads — se usi conversioni Ads, inserisci i tuoi valori nelle variabili dedicate.
  • Evento GA4 — controlla nome evento e parametri (es. phone_click).
  • Trigger sui link telefono — devono intercettare i link tel: del tuo sito. Se usi bottoni custom senza tel:, va adattato il trigger.
Attenzione Se i numeri di telefono non sono link cliccabili (), il tracking non partirà finché non allinei HTML o trigger.

4 Test e pubblicazione

  1. In GTM clicca Anteprima (Preview) e collega il tuo sito.
  2. Clicca un numero di telefono sulla pagina.
  3. Nella console di debug GTM verifica che tag e trigger si attivino.
  4. Controlla anche GA4 → DebugView (e Google Ads, se configurato).
  5. Quando tutto è ok, clicca Invia → Pubblica sul container.

5 Serve aiuto?

Se il sito ha una struttura particolare dei link telefono, potrebbe servire un piccolo adattamento dei trigger.
