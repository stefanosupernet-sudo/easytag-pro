Istruzioni di installazione

Prodotto: Tracking Click sul Numero di Telefono con Google Tag Manager

1. Cosa hai ricevuto

  • container.json – esportazione del contenitore GTM già configurato
  • Queste istruzioni

2. Come importare il container

  1. Accedi al tuo account Google Tag Manager.
  2. Seleziona (o crea) il container del sito su cui vuoi installare il tracking.
  3. Vai in Admin → Container → Import Container.
  4. Carica il file container.json che hai scaricato.
  5. Scegli l’opzione di merge più adatta (di solito “Overwrite” se è un container nuovo, oppure “Merge” se ne hai già uno attivo).
  6. Controlla l’anteprima e conferma l’importazione.

3. Cosa personalizzare dopo l’import

Dopo l’importazione verifica e, se necessario, modifica:

  • Evento GA4 (nome evento e parametri)
  • Eventuale Conversion ID / Label di Google Ads
  • Trigger sui selettori CSS o sui link tel: (adatta al tuo HTML se diverso)

4. Pubblicazione

  1. Usa la modalità Anteprima di GTM e testa un click sul numero di telefono.
  2. Verifica che l’evento arrivi correttamente in GA4 (DebugView) e, se configurato, in Google Ads.
  3. Quando tutto è ok, pubblica il container.
Nota: Questo è un template di riferimento. Se il tuo sito ha una struttura particolare dei link telefono, potrebbe essere necessario un piccolo adattamento dei trigger. In caso di dubbi scrivi a support@easytag.com.
