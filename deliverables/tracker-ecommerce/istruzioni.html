Istruzioni di installazione

Prodotto: Tracker Completo Conversioni E-commerce con Google Tag Manager

1. Cosa hai ricevuto

  • container.json – esportazione del contenitore GTM già configurato
  • Queste istruzioni

2. Prerequisito importante

Questo container si aspetta un data layer e-commerce già presente sul sito (o da implementare). Gli eventi standard supportati sono:

  • view_item / view_item_list
  • add_to_cart / remove_from_cart
  • begin_checkout
  • add_shipping_info / add_payment_info
  • purchase

3. Come importare il container

  1. Accedi a Google Tag Manager.
  2. Admin → Container → Import Container → carica container.json.
  3. Scegli l’opzione di merge più adatta.
  4. Conferma.

4. Cosa personalizzare

  • Measurement ID di GA4
  • Eventuali Conversioni Google Ads collegate agli eventi di acquisto
  • Verifica che i nomi degli eventi del tuo data layer corrispondano a quelli previsti dal container

5. Test e pubblicazione

  1. Usa la modalità Anteprima di GTM + GA4 DebugView.
  2. Simula il percorso di acquisto (visualizzazione prodotto → carrello → checkout → purchase).
  3. Verifica che tutti gli eventi e i parametri (value, currency, items, transaction_id) arrivino correttamente.
  4. Pubblica.
Nota: Se il tuo e-commerce non ha ancora un data layer standard, potremmo aver bisogno di un intervento aggiuntivo di implementazione. Scrivi a support@easytag.com per una valutazione.
