Tracker conversioni e-commerce

Questa guida vale dopo che hai ricevuto il container personalizzato per il tuo CMS / data layer.

Indice
  1. Prerequisito: data layer
  2. Eventi supportati
  3. Import in GTM
  4. Personalizzazioni
  5. Test percorso acquisto
  6. Supporto

1 Prerequisito: data layer

Il tracking e-commerce funziona se il sito espone un data layer (o equivalente) con gli eventi di navigazione e acquisto. Se non c’è ancora, fa parte del lavoro concordato nel preventivo.

ImportanteSenza data layer allineato, i tag GTM non possono “indovinare” carrello e acquisti in modo affidabile.

2 Eventi tipicamente supportati

  • view_item / view_item_list
  • add_to_cart / remove_from_cart
  • begin_checkout
  • add_shipping_info / add_payment_info
  • purchase (con value, currency, items, transaction_id)

3 Import in GTM

  1. Apri Google Tag Manager e seleziona il container del sito.
  2. Admin → Container → Import Container → carica il container.json ricevuto.
  3. Preferisci Merge se ci sono già altri tag.
  4. Conferma dopo aver rivisto l’anteprima.

4 Personalizzazioni da verificare

  • Measurement ID GA4
  • Conversioni Google Ads collegate al purchase (se richieste)
  • Nomi eventi e parametri allineati al tuo data layer reale

5 Test del percorso d’acquisto

  1. Anteprima GTM + GA4 DebugView.
  2. Simula: scheda prodotto → carrello → checkout → ordine di test.
  3. Verifica value, currency, items e transaction_id sull’evento purchase.
  4. Pubblica solo quando il percorso è completo.

6 Supporto
