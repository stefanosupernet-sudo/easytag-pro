# Easy Tag

**Spin-off del team italiano proveniente dagli uffici Google di Cracovia.**

Sito e-commerce e di supporto tecnico specialistico su Google Tag Manager, GA4 e tracking e-commerce per uffici tecnici e agenzie di web marketing.

Lingua primaria: **Italiano**  
Seconda lingua: **English** (`/en`)

## Stack previsto (Fase 1)
- Frontend statico (HTML/CSS/JS) o Next.js
- Hosting: Vercel / Netlify
- Pagamenti: Stripe Checkout
- Form: Formspree / Netlify Forms / email diretta
